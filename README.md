# My Digital Directory — สมุดรายชื่อดิจิทัล

แอปพลิเคชัน Flutter สำหรับบันทึกรายชื่อผู้ติดต่อ (ชื่อ เบอร์โทร อีเมล) ลงฐานข้อมูล SQLite
ข้อมูลถูกเก็บในเครื่อง ปิดแอปแล้วเปิดใหม่ข้อมูลยังอยู่ครบ

---

## ความสามารถ

| ความสามารถ | รายละเอียด |
| --- | --- |
| บันทึก (Create) | ฟอร์มกรอกชื่อ เบอร์โทร อีเมล พร้อมตรวจความถูกต้องก่อนบันทึก |
| เรียกดู (Read) | แสดงเป็นการ์ดใน `ListView.builder` เลื่อนดูได้ทั้งหมด |
| แก้ไข (Update) | แตะที่การ์ดเพื่อเปิดฟอร์มพร้อมข้อมูลเดิม แก้แล้วบันทึกทับ |
| ลบ (Delete) | กดถังขยะ มีกล่องยืนยันก่อนลบจริง |
| ค้นหา | พิมพ์แล้วค้นทันที ค้นได้ทั้งชื่อ เบอร์ และอีเมล ด้วยคำสั่ง SQL `LIKE` |
| รายการโปรด | ติดดาวรายชื่อสำคัญ และกรองดูเฉพาะรายการที่ติดดาว |
| เรียงลำดับ | สลับระหว่าง "ใหม่สุด" กับ "ตามชื่อ" |
| แดชบอร์ด | การ์ดตัวเลข 3 ใบ กราฟแท่ง 7 วัน อักษรขึ้นต้นที่พบบ่อย และ 3 รายชื่อล่าสุด |

## Widget ที่ใช้ (เกินเกณฑ์ขั้นต่ำ 4 แบบ)

`Text` · `ListView.builder` · `ListView.separated` · `Card` · `TextFormField` · `SnackBar`
`AlertDialog` · `FloatingActionButton.extended` · `NavigationBar` · `CircleAvatar` · `FilterChip`
`SwitchListTile` · `RefreshIndicator` · `Wrap` · `IndexedStack` · `Row` / `Column` / `Padding` / `Expanded`

## โครงสร้างไฟล์

```
lib/
├── main.dart                      จุดเริ่มต้นของแอป
├── main_web.dart                  จุดเริ่มต้นสำหรับรันบนเว็บ
├── models/
│   └── contact.dart               โครงข้อมูลผู้ติดต่อ + แปลงเป็น/จาก Map ของฐานข้อมูล
├── data/
│   ├── database_helper.dart       เปิดฐานข้อมูล สร้างตาราง และอัปเกรดโครงสร้าง
│   ├── contact_repository.dart    คำสั่ง SQL ทั้งหมด และการรวมตัวเลขสำหรับแดชบอร์ด
│   ├── db_factory.dart            เลือก factory ตามแพลตฟอร์ม (conditional export)
│   ├── db_factory_io.dart         สำหรับมือถือ / เดสก์ท็อป
│   └── db_factory_web.dart        สำหรับเว็บ (SQLite ผ่าน WebAssembly)
├── screens/
│   ├── home_shell.dart            โครงหลัก + แถบเมนูล่าง 2 แท็บ
│   ├── contacts_screen.dart       หน้ารายการ ค้นหา กรอง เรียง ลบ
│   ├── contact_form_screen.dart   ฟอร์มเพิ่ม/แก้ไข (ใช้หน้าเดียวกัน)
│   └── dashboard_screen.dart      หน้าสรุปตัวเลข
├── widgets/
│   ├── contact_card.dart          การ์ดผู้ติดต่อ 1 คน
│   ├── stat_card.dart             การ์ดตัวเลขสรุป
│   ├── weekly_bar_chart.dart      กราฟแท่ง 7 วัน (วาดเอง ไม่ใช้ไลบรารีนอก)
│   └── empty_state.dart           ข้อความเมื่อไม่มีข้อมูล
├── theme/
│   └── app_theme.dart             สี ระยะห่าง และธีมกลางของแอป
└── utils/
    └── validators.dart            ตรวจชื่อ เบอร์โทร และอีเมล
```

หลักการแบ่ง: หน้าจอไม่เขียน SQL เอง เรียกผ่าน `ContactRepository` อย่างเดียว
ถ้าวันหลังเปลี่ยนไปใช้ฐานข้อมูลอื่น แก้แค่โฟลเดอร์ `data/`

## โครงสร้างฐานข้อมูล

ตาราง `contacts`

| คอลัมน์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| `id` | INTEGER PRIMARY KEY AUTOINCREMENT | รหัสประจำแถว |
| `name` | TEXT NOT NULL | ชื่อผู้ติดต่อ |
| `phone` | TEXT NOT NULL | เบอร์โทร |
| `email` | TEXT NOT NULL | อีเมล |
| `is_favorite` | INTEGER NOT NULL DEFAULT 0 | 0 = ปกติ, 1 = รายการโปรด |
| `created_at` | TEXT NOT NULL | เวลาที่บันทึกครั้งแรก (ISO 8601) |
| `updated_at` | TEXT NOT NULL | เวลาที่แก้ไขล่าสุด (ISO 8601) |

SQLite ไม่มีชนิด `bool` และ `DateTime` จึงเก็บเป็น `0/1` และสตริง ISO 8601

### การอัปเกรดโครงสร้าง

เวอร์ชัน 1 มี 4 คอลัมน์ เวอร์ชัน 2 เพิ่มอีก 3 คอลัมน์
ใช้ `onUpgrade` + `ALTER TABLE` แทนการลบตารางทิ้ง รายชื่อที่ผู้ใช้บันทึกไว้ตั้งแต่เวอร์ชันเก่าจึงไม่หาย

---

## การตรวจความถูกต้องของข้อมูล

- ชื่อ: ห้ามว่าง และต้องยาวอย่างน้อย 2 ตัวอักษร
- เบอร์โทร: ต้องมีตัวเลขอย่างน้อย 9 หลัก (นับเฉพาะตัวเลข พิมพ์ขีดคั่นได้)
- อีเมล: ต้องตรงรูปแบบ `name@domain.com`

---

## แนวคิดการออกแบบหน้าจอ

- พื้นหลังเป็นน้ำเงินเข้ม `#0F172A` ไม่ใช้ดำสนิท เพราะดำสนิทคู่กับตัวอักษรขาวให้ค่า contrast สูงเกินไปจนอ่านนาน ๆ แล้วล้าตา
- ผิวการ์ดไล่ระดับ 2 ชั้น (`#1A2438` และ `#243147`) เพื่อให้เห็นลำดับความลึกโดยไม่ต้องใช้เส้นขอบหนา
- คู่สีตัวอักษรทุกคู่ผ่านเกณฑ์ contrast ขั้นต่ำ 4.5:1 ตามมาตรฐาน WCAG AA
- ปุ่มที่กดได้เว้นระยะห่างกันอย่างน้อย 8 pt ลดการกดพลาด
- ใช้แถบเมนูล่างแทนเมนูข้าง เพราะนิ้วโป้งเอื้อมถึงง่ายกว่าเมื่อถือมือถือมือเดียว

## วิธีรัน

ติดตั้ง dependency ก่อนเสมอ

```bash
flutter pub get
```

รันบนมือถือหรืออีมูเลเตอร์

```bash
flutter run
```

รันบนเว็บ (ต้องเตรียมไฟล์ SQLite สำหรับเว็บครั้งแรกครั้งเดียว)

```bash
dart run sqflite_common_ffi_web:setup
flutter run -d chrome -t lib/main_web.dart
```

สร้างไฟล์ APK

```bash
flutter build apk --release
```

ไฟล์ผลลัพธ์อยู่ที่ `build/app/outputs/flutter-apk/app-release.apk`

ตรวจคุณภาพโค้ด

```bash
flutter analyze
```

## หมายเหตุ

โปรเจกต์นี้มีเฉพาะโฟลเดอร์ `lib/` กับไฟล์ตั้งค่า หากยังไม่มีโฟลเดอร์ `android/` `ios/` `web/`
ให้สร้างขึ้นมาด้วยคำสั่งเดียว โดยรันในโฟลเดอร์โปรเจกต์

```bash
flutter create .
```

คำสั่งนี้เติมเฉพาะไฟล์แพลตฟอร์มที่ขาด ไม่แตะไฟล์ใน `lib/` ที่มีอยู่แล้ว
